# COVID-19 Country-Wise Analysis

## Project Overview
This project explores the **country-wise COVID-19 dataset** to uncover patterns in confirmed cases, deaths, recoveries, and weekly changes.  
The goal is to demonstrate **data analysis, visualization, and storytelling skills** using Python, Pandas, Seaborn, and Matplotlib.

## Objectives
- Perform **exploratory data analysis (EDA)** on global COVID-19 metrics.
- Investigate **correlations** between confirmed cases, deaths, and recoveries.
- Analyze **mortality and recovery rates** across countries and WHO regions.
- Visualize **skewness and distribution** of numeric features.
- Identify **weekly growth trends** and highlight countries with significant changes.

## Tools & Libraries
- **Pandas** → Data cleaning, aggregation, and statistical summaries.
- **Seaborn & Matplotlib** → Heatmaps, scatter plots, histograms, and bar charts.
- **NumPy** → Numerical operations.
- **Jupyter Notebook** → Interactive analysis and visualization.

## Key Analyses
1. **Correlation Matrix Heatmap**  
   - Shows strong associations between confirmed cases and deaths, and between new cases and new deaths.
2. **Skewness Investigation**  
   - Highlights countries with extreme case counts (e.g., USA, Brazil, India).
3. **Regional Comparisons**  
   - WHO regions differ significantly in average confirmed cases and mortality rates.
4. **Mortality & Recovery Insights**  
   - Some countries show high death-to-recovery ratios, indicating healthcare strain.
5. **Weekly Change Analysis**  
   - Identifies countries with rapid increases in cases week-over-week.

## Visualizations
- Heatmap of correlations between COVID-19 metrics.
- Scatter plots (Confirmed vs Deaths/100Cases).
- Histograms showing skewness of distributions.
- Bar plots comparing WHO regions.
